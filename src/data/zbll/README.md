# ZBLL 数据说明

本目录同时存在两类文件，用途不同：

| 文件 | 状态 | 说明 |
| :--- | :--- | :--- |
| `zbll_{u,l,h,pi,s,as}.js` | **唯一数据源** | 应用实际 import 的文件，已人工清洗公式与分组。 |
| `zbll_*_cases.json` | 只读中间产物 | 当初从视频抽帧 OCR 得到的原始识别结果，含大写 `Y`、西里尔字母等噪声。**不要直接据此重新生成 `.js`**，否则会把噪声写回线上数据。 |

`../zbllTCases.js`（Set T）没有对应的 JSON，一直是手工维护。

修改 ZBLL 数据时请直接编辑 `.js` 文件，并在提交前执行：

```bash
npm run verify
```

该脚本会校验 633 条案例的数量、id 唯一性、分组引用、时间轴、图片存在性，以及公式能否被 `invertAlgorithm` 正确解析（会报出混入公式字段的非转动文字）。
