# CubeDex

三阶魔方速拧手法速查与练习系统，涵盖 CFOP、ZBLL 与 Roux CMLL 共 633 种情况。提供手法演示视频点播、单手法循环播放、中英文无缝切换、逆向打乱公式推导与本地学习进度管理。

* **线上地址**：[https://deck.ltd/cfop/](https://deck.ltd/cfop/)

---

## 包含内容

| 模块 | 包含情况数 | 说明 |
| :--- | :---: | :--- |
| **CFOP** | 119 | F2L (41 种，含起手姿态标识)、OLL (57 种)、PLL (21 种) |
| **ZBLL** | 472 | 顶棱十字对齐时顶层一步还原，分为 T / U / L / H / Pi / S / AS 7 大组 |
| **CMLL** | 42 | Roux 桥式顶角一步还原，分为 O / H / Pi / U / T / L / S / AS 8 组 |

---

## 主要功能

* **时间轴视频点播**：点击任意 Case 直接跳转至对应视频演示片段。
* **单手法循环（Loop）**：支持单个 Case 循环重播，方便双手持魔方跟练。
* **打乱公式推导**：根据解法公式自动生成逆向打乱公式（Scramble），支持解法/打乱一键复制。
* **掌握度标记**：本地保存已掌握情况，支持按“全部 / 待练 / 已过”快速筛选。
* **中英文一键切换**：顶栏支持中文与英文版本一键无缝切换，界面与术语全量双语化。
* **PWA 支持**：支持添加到桌面或手机主屏幕作为独立应用运行，具备离线页面缓存。
* **键盘快捷操作**：全套快捷键支持双手练拧时的无鼠标盲操。

---

## 快捷键列表

| 按键 | 功能 |
| :--- | :--- |
| **`空格`** | 播放 / 暂停 |
| **`←` / `→`** 或 **`J` / `K`** | 快退 2 秒 / 快进 2 秒 |
| **`R`** | 重头播放当前 Case |
| **`L`** | 切换单 Case 循环模式 |
| **`1` ~ `4`** | 切换倍速 (0.5x / 0.75x / 1.0x / 1.25x) |
| **`Shift + 1 ~ 3`** | 切换 CFOP 模块 (F2L / OLL / PLL) |
| **`Shift + 4 / 5`** | 切换高阶模块 (ZBLL / CMLL) |

## 技术架构

* **前端框架**：React 19 + Vite + Tailwind CSS v4
* **图标与动效**：Lucide React / Canvas Confetti
* **字体**：本地打包 Fragment Mono & Schibsted Grotesk (WOFF2)
* **媒体分发**：视频文件托管于腾讯云 COS + CDN，采用 HTTP 206 分段流式加载，本地仓库不包含视频文件。

## 本地开发与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务 (http://localhost:5173)
npm run dev

# 编译生产包 (输出至 dist/)
npm run build
```
