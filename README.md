# Cube-Tutor — CFOP (F2L / OLL / PLL) 极速手法精讲与速查系统

专为三阶魔方进阶与竞速玩家打造的交互式教学、速查与指法打磨平台。  
基于 **csTimer** 官方规范与分类体系，深度整合前三阶单次世界纪录保持者 **杜宇生（2023）** 权威教学体系，涵盖 **CFOP 全部 119 个 Case**（F2L 41 种 + OLL 57 种 + PLL 21 种），支持毫秒级视频点播、单手法无缝循环、打乱逆向推导与掌握度追踪。

---

## 🌟 三大核心模块 (CFOP 119 Cases Full Coverage)

本项目完整涵盖了三阶魔方高级速拧 CFOP 还原法的后三步核心内容：

```
                    ┌─── [ F2L 41 种 ] ─── 前两层棱角同入，奠定速拧速度基石
                    │
CFOP 速查与练习体系 ┼─── [ OLL 57 种 ] ─── 顶层黄色定向，杜宇生保稳实战手法
                    │
                    └─── [ PLL 21 种 ] ─── 顶层位置置换，全部 SUB1 极速手法
```

### 1. F2L (First Two Layers / 前两层 41 种常规手法)
- **教程来源**：杜宇生（2023）《我的41条F2L常规做法》
- **分类标准**：基于 csTimer 9 大分类标签（Easy 基础入槽、RE 顶层分离棱块归位、REFC 顶面白色色向调整、PMS 连体搭配、SPGO 顶色相同、Weird 特殊别扭情况、CPEU 角在底槽棱在顶层、EPCU 棱在底槽角在顶层、ECP 棱角均在底槽）。
- **特色**：包含杜宇生独家指法起手姿态（`中起手` / `上起手` / `下起手`），清晰标明形态速认特征。

### 2. OLL (Orientation of the Last Layer / 顶层定向 57 种手法)
- **教程来源**：杜宇生（2023）《我的57条OLL保稳手法演示》
- **分类标准**：基于标准魔方形态划分为 10 大分类：
  - 十字 O (OCLL - 7 种经典小鱼、双头鱼、十字与大 U 翻角)
  - 点 O (Dot - 8 种纯点无黄色棱块形态)
  - 小鱼形 (Fish - K 字与 Y 字形态)
  - T 形 (T-Shapes)、U 形 (U-Shapes)、L 形 (L-Shapes)
  - C 形 (C-Shapes)、W 形 (W-Shapes)
  - 闪电形 (Lightning) 与 平行线形 (Line)
- **特色**：精选保稳手法，兼顾高转速与容错率，彻底消除复杂 OLL 的辨识迟疑。

### 3. PLL (Permutation of the Last Layer / 顶层置换 21 种 SUB1 手法)
- **教程来源**：杜宇生（2023）《我的PLL手法演示(全部SUB1)》
- **分类标准**：包含全部 21 种经典置换情况：
  - 三棱换：`Ua`、`Ub`
  - 四棱换：`H`、`Z`
  - 三角换：`Aa`、`Ab`
  - 四角换与对角邻棱：`E`、`V`、`Y`、`Na`、`Nb`
  - 邻角邻棱换：`Ra`、`Rb`、`Ja`、`Jb`、`F`
  - G 排列：`Ga`、`Gb`、`Gc`、`Gd`
- **特色**：杜宇生原版竞速指法，全部手法均达到 SUB1（1 秒内复原）极速演示。

## ⚡ 核心功能与亮点

1. **精准毫秒级时间轴直达**：
   - 点击任一 Case 卡片，播放器即刻精确跳转至对应手法的实况演示起始点，无需在漫长的视频中手动反复拖动进度条。
2. **A-B 单手法自动循环（Loop Mode）**：
   - 支持单个 Case 视频片段无缝循环重播。双手握魔方练习时，视频自动一遍遍演示手法，无需手动点击重播，边看边拧，高效强化肌肉记忆。
3. **逆向打乱公式推导（Scramble Setup）**：
   - 系统内置算法自动对每条求解公式进行逆向推导，生成对应的标准打乱公式（Scramble）。在已复原的魔方上直接执行打乱公式，即可快速复现目标 Case，方便随时实战验证。
4. **SOLUTION / SCRAMBLE 一键复制**：
   - 提供求解公式与打乱公式的独立选项卡，支持一键复制到剪贴板，可无缝粘贴至 csTimer、Cubeast 等计时器软件中导入训练。
5. **LineLore 工业美学新野兽派 UI**：
   - 界面参考 LineLore 设计语言，采用高对比黑白灰底色搭配经典 Safety Orange（`#ff5b00`）警示橙强调色。
   - 采用 Schibsted Grotesk 无衬线主字体与 Fragment Mono 硬核等宽字体，直角方块化卡片与控制栏，打造严肃纯粹的专业测速仪表感。
6. **响应式设备自适应**：
   - **桌面端**：左侧主视频与控制台 + 右侧三列 Case 网格列表，视窗底部 0px 严密齐平，两栏独立滚动互不影响。
   - **移动端**：视频区域在页面上滚时吸顶锁定，控制栏全要素单行紧凑排布无折行，分类面板支持一键收起展开，极大释放竖屏操作空间。
7. **学习进度与掌握度追踪**：
   - 本地持久化记录（localStorage），点击卡片勾选标记已掌握的 Case。顶部导航栏实时统计当前模块的掌握率百分比，掌握全部 Case 触发撒花激励。
8. **极致性能加载优化**：
   - 3D 魔方插图全部转换为现代 WebP 格式，并开启 HTTP/2 多路复用与长效静态缓存。
   - 视频资源剔除音轨并开启 FastStart 流式加载，首屏秒开无等待。

## ⌨️ 双手速拧 · 全套键盘快捷键

双手握魔方时，无需触碰鼠标即可通过键盘全功能控制：

| 按键 | 功能说明 |
| :--- | :--- |
| **`空格 (Space)`** | 播放 / 暂停视频 |
| **`←` / `→` (方向键)** | 快退 2 秒 / 快进 2 秒（精准微调手法动作） |
| **`J` / `K`** | 快退 2 秒 / 快进 2 秒（右手速拧备用操作键） |
| **`R`** | 重新播放当前 Case（从头演示） |
| **`L`** | 切换单 Case 循环播放 / 停止循环（LOOP 模式） |
| **`1` ~ `4`** | 切换播放倍速（`1`: 0.5x, `2`: 0.75x, `3`: 1.0x, `4`: 1.25x） |
| **`Shift + 1 / 2 / 3`** | 极速切换三大模块（`Shift+1`: F2L, `Shift+2`: OLL, `Shift+3`: PLL） |
