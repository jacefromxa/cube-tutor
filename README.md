# Cube-Tutor — 三阶速拧全谱速查与训练系统
> **CFOP (119 Cases) · ZBLL 顶层一步还原 (472 Cases) · Roux 桥式 CMLL (42 Cases)**

专为三阶魔方进阶、高阶竞速与盲拧练习玩家打造的交互式教学、速查与指法打磨平台。  
基于 **csTimer** 官方规范与分类体系，深度整合前三阶单次世界纪录保持者 **杜宇生（2023）** 与 **RusselWang** 权威教学体系，涵盖 **全部 633 种速拧 Case**，支持毫秒级视频点播、单手法无缝循环、逆向打乱公式推导、学习进度持久化追踪与 PWA 离线访问。

### 1. CFOP 核心还原体系 (119 种手法)
* **F2L (First Two Layers / 前两层 41 种常规手法)**
  * **教学来源**：杜宇生（2023）《我的41条F2L常规做法》
  * **分类规范**：基于 csTimer 9 大分类（Easy 基础入槽、RE 顶层分离棱块归位、REFC 顶面白色色向调整、PMS 连体搭配、SPGO 顶色相同、Weird 特殊别扭情况、CPEU 角在底槽棱在顶层、EPCU 棱在底槽角在顶层、ECP 棱角均在底槽）。
  * **起手姿态标识**：精准标注独家实战指法姿态（`中起手` / `上起手` / `下起手`）。
* **OLL (Orientation of the Last Layer / 顶层定向 57 种手法)**
  * **教学来源**：杜宇生（2023）《我的57条OLL保稳手法演示》
  * **分类规范**：十字 O (OCLL)、点 O (Dot)、小鱼形 (Fish)、T/U/L/C/W 形、闪电形与平行线形等 10 大分类。
  * **核心特色**：精选保稳手法，兼顾高转速与容错率，消除识别迟疑。
* **PLL (Permutation of the Last Layer / 顶层置换 21 种 SUB1 手法)**
  * **教学来源**：杜宇生（2023）《我的PLL手法演示(全部SUB1)》
  * **分类规范**：包含三棱换 (`Ua`/`Ub`)、四棱换 (`H`/`Z`)、三角换 (`Aa`/`Ab`)、四角换 (`E`/`V`/`Y`/`Na`/`Nb`)、邻角邻棱换 (`Ra`/`Rb`/`Ja`/`Jb`/`F`) 与 G 排列 (`Ga`~`Gd`)。
  * **核心特色**：原版竞速指法，全部手法均达到 SUB1（1秒内复原）极速实况演示。

### 2. ZBLL 1LL 高阶体系 (472 种手法一步还原)
* **教学来源**：RusselWang 示范教学体系
* **体系说明**：在 F2L 完成且顶层黄色棱块已构成十字的条件下，**仅用一条公式同时完成顶层翻色与位置置换（1LL 一步还原）**，是三阶速拧走向顶级 SUB7 / SUB6 的必修王牌。
* **分类系统**：按顶角黄色朝向分为 7 大字母系统，每组均配备专属抽屉式二级细分子集与 3D 俯视图例：
  * **Set T (72 种)**：T-DIAG、T-ADJ-B、T-ADJ-F、T-ADJ-L、T-ADJ-R、T-2GLL
  * **Set U (72 种)**：U-DIAG、U-ADJ-B、U-ADJ-F、U-ADJ-L、U-ADJ-R、U-2GLL
  * **Set L (72 种)**：L-DIAG、L-ADJ-B、L-ADJ-F、L-ADJ-L、L-ADJ-R、L-2GLL
  * **Set H (40 种)**：H-DIAG、H-ADJ、H-2GLL
  * **Set Pi (72 种)**：Pi-DIAG、Pi-ADJ-B、Pi-ADJ-F、Pi-ADJ-L、Pi-ADJ-R、Pi-2GLL
  * **Set S (72 种)**：S-DIAG、S-ADJ-B、S-ADJ-F、S-ADJ-L、S-ADJ-R、S-2GLL
  * **Set AS (72 种)**：AS-DIAG、AS-ADJ-B、AS-ADJ-F、AS-ADJ-L、AS-ADJ-R、AS-2GLL

### 3. CMLL Roux 桥式体系 (42 种手法)
* **教学来源**：RusselWang 示范教学体系
* **体系说明**：桥式（Roux Method）核心第 3 步——在保持前两步六面底桥不受破坏的前提下，**一步复原顶层 4 个角块的色向与位置**。
* **形态全览**：包含 `O` (2 种，纯角换)、`H` (4 种，双头灯)、`Pi` (6 种，滑车)、`U` (6 种，U 形)、`T` (6 种，T 形)、`L` (6 种，领结)、`S` (6 种，小鱼)、`AS` (6 种，反鱼)。

## ⚡ 核心功能与技术亮点

### 1. 毫秒级时间轴与循环精练 (Loop Mode)
* **精准时间轴直达**：点击任一 Case 卡片，播放器即刻跳转至对应手法实况演示的起始毫秒，无需在几十分钟的长视频中手动寻找。
* **A-B 单手法自动循环**：支持单 Case 片段无缝循播。双手持魔方练习时边看边拧，无需碰触鼠标，极大提升肌肉记忆训练效率。

### 2. 逆向打乱推导与公式一键复制
* **逆向打乱生成（Scramble Setup）**：系统内置算法自动推导每条求解公式的逆向打乱公式（Scramble）。在已复原的魔方上直接执行打乱公式，即可快速复现目标 Case。
* **一键复制**：提供求解公式（SOLUTION）与打乱公式（SCRAMBLE）的独立选项卡，支持一键复制到剪贴板，可无缝粘贴至 csTimer、Cubeast 等计时器软件中导入训练。

### 3. 生产级媒体架构（腾讯云 COS + 全球 CDN 加速）
* **超轻量代码仓库**：11 个核心高清教学视频全量托管于腾讯云对象存储（COS）与全球 CDN 边缘节点（`https://media.deck.ltd/videos/`）。
* **流式加载体验**：启用 HTTP 206 Partial Content 分段流式传输，视频点播秒开且免受本地存储限制。构建产物完全剥离本地视频（体积仅约 28MB），秒级 Git 提交与极速服务器热更新。

### 4. PWA 离线支持与本地化体验
* **独立 Web App 体验**：支持将站点以 PWA 形式直接安装/添加到手机主屏幕，具备沉浸式全屏视图与独立应用图标。
* **Service Worker (v2) 智能缓存**：
  * HTML 文档采用 **Network-First（网络优先）** 策略，线上发布新版本即刻生效，告别陈旧缓存困扰。
  * 静态哈希资源、图片、本地字体采用 **Stale-While-Revalidate** 离线长效缓存。
  * 严格隔离视频流与 CDN 请求，零额外内存与带宽开销。
* **字体完全本地化**：内置并本地托管 [Fragment Mono](public/fonts/fragment-mono-400.woff2) 与 [Schibsted Grotesk](public/fonts/schibsted-grotesk.woff2) WOFF2 字体，彻底切断外部 Google Fonts 依赖，消除大陆网络卡顿与加载阻断。

### 5. LineLore 工业美学新野兽派 UI
* 借鉴 LineLore 设计语言：纯粹的高对比工业黑白底色，搭配标志性 LineLore 警示橙（Safety Orange `#ff5b00`）高亮与全域文本划选定制。
* 严谨的直角方块、硬核等宽排版、技术仪表板参数标签，打造严肃专注文艺的数字速拧工具箱。

### 6. 移动端深度工程打磨
* **播放器物理锁定（钉死）**：移动端顶部内边距归零，播放器紧贴 Header 吸顶，下滚时 0 像素位移脱节；外层 100% 视口实心遮蔽背景（`#0a0a0a` / `#f4f4f5`），下方卡片整齐从底面穿行，**彻底解决卡片滚动漏出穿帮问题**。
* **顶栏无阻横向滑动**：模块栏采用左对齐启动（`justify-start sm:justify-center`）配合平滑横向滚动，**最左侧 F2L 按钮永不被边缘裁切**。
* **双端像素级绝对齐平**：播放器卡片与下方的分类抽屉、Case 网格在移动端左右间距与宽度严格一致（实测对齐误差 0 像素）。
* **交互式学习进度胶囊**：顶部 Row 1 的进度小胶囊不仅实时显示掌握百分比，还支持轻触直接在 `全部` ➔ `待练` ➔ `已过` 之间循环筛选。

## ⌨️ 双手速拧 · 全套键盘快捷键

双手握魔方练习时，无需触碰鼠标即可通过键盘全功能盲操控制：

| 按键 | 功能说明 |
| :--- | :--- |
| **`空格 (Space)`** | 播放 / 暂停视频 |
| **`←` / `→` (方向键)** | 快退 2 秒 / 快进 2 秒（精准微调手法动作） |
| **`J` / `K`** | 快退 2 秒 / 快进 2 秒（右手速拧备用操作键） |
| **`R`** | 重新播放当前 Case（从头演示） |
| **`L`** | 切换单 Case 循环播放 / 停止循环（LOOP 模式） |
| **`1` ~ `4`** | 切换播放倍速（`1`: 0.5x, `2`: 0.75x, `3`: 1.0x, `4`: 1.25x） |
| **`Shift + 1 / 2 / 3`** | 极速切换 CFOP 三大核心模块（`1`: F2L, `2`: OLL, `3`: PLL） |
| **`Shift + 4 / 5`** | 极速切换高阶扩展模块（`4`: ZBLL 472, `5`: CMLL 42） |

## 🚀 本地开发与启动

### 1. 克隆与安装依赖
```bash
git clone https://github.com/jacefromxa/cube-tutor.git
cd cube-tutor
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器打开：[http://localhost:5173](http://localhost:5173)

### 3. 构建生产包
```bash
npm run build
```
编译产物将输出至 `dist/` 目录，可直接托管于 Nginx、Vercel、Cloudflare Pages 等静态托管环境。
