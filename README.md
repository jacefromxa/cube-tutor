# 魔方 F2L 41 种常规手法交互速查系统

基于 **csTimer** 官方分类与编号体系，深度整合 **杜宇生（2023）《我的41条F2L常规做法》** 高清教学视频，专为三阶魔方进阶与速拧玩家打造的现代化交互式 F2L 练习速查平台。

---

## 🌟 核心功能

1. **41 种 F2L Case 精准图形化展示**：
   - 提取原视频 1080P 高清 3D 魔方图形，保留原汁原味视角与块向高亮标记。
   - 标明 csTimer 标准分类名（`Easy-01`、`RE-05`、`SPGO-15` 等）与分组标签。
   - 提供杜宇生独家指法起手提示（`中起手` / `上起手` / `下起手`）及形态速认特征。

2. **点击直达视频实况**：
   - 点击任一 Case 卡片，播放器即刻毫秒级跳转到杜宇生实况演示片段。
   - **单段循环练习（Loop Mode）**：支持 A-B 自动循环播放当前 Case，无需反复手动回退，边看边拧。
   - **多档倍速调节**：支持 `0.5x`、`0.75x`、`1.0x`、`1.25x`，慢动作细致拆解指法手法。
   - **快进快退与重播**：快捷键 `J` / `K` 快退快进 2 秒，`R` 键一键重播当前手法。

3. **智能检索与灵活排序**：
   - **多维筛选**：按 csTimer 9 大分类标签（Easy、RE、REFC、PMS、SPGO、Weird、CPEU、EPCU、ECP）极速筛选。
   - **模糊搜索**：支持搜索编号（如 `15`、`25`）、分类（如 `SPGO`）、公式步骤（如 `R U R'`、`Keyhole`）及起手法。
   - **多模式排序**：支持按 **csTimer 分类**、**csTimer 编号（#01-41）** 或 **视频实况时间轴（00:11-11:40）** 切换。

4. **学习进度与掌握度追踪**：
   - 本地持久化记录（localStorage），点击卡片勾选标记已掌握的 Case。
   - 顶部实时统计掌握百分比进度条，标记成功触发撒花动效。

5. **双手无忧 · 全套键盘快捷键**：
   - `空格 (Space)`：播放 / 暂停视频
   - `←` / `→`：上一个 / 下一个 Case
   - `R`：重播当前手法
   - `L`：开启 / 关闭单段循环
   - `J` / `K`：快退 2 秒 / 快进 2 秒
   - `1` ~ `4`：快速切换 0.5x / 0.75x / 1.0x / 1.25x 倍速
   - `M`：静音切换
   - `F`：全屏播放
   - `Esc`：关闭弹窗

## 🚀 启动与运行

项目已完成构建并在本地启动：

```bash
# 本地开发服务器（默认已运行在 5173 端口）
npm run dev
```

在浏览器打开：[http://localhost:5173](http://localhost:5173) 即可使用。
